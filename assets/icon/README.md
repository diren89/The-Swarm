# Icon

Signet von The Swarm: Vier Flugbahnen laufen spiralförmig auf einen gemeinsamen Punkt zu. Viele Agents, ein Ziel.

Gestaltet nach der Signet-Grammatik des Designsystems [ODSV](https://github.com/diren89/odsv) (SPEC 10.6): vier Striche mit 26 Einheiten auf 400 × 400, runde Enden, Farbfolge Pink → Orange → Hellorange → Gelb, genau ein gelber Punkt als Fokus.

| Datei | Zweck |
| --- | --- |
| `the-swarm-icon.svg` | App-Icon, Motiv zentriert auf dunkler Kachel |
| `the-swarm-signet.svg` | Signet für Karte, Hero oder Titelfolie (Motiv rechts, Wortmarke unten links frei) |
| `the-swarm-icon-{32,180,512,1024}.png` | Rastergrößen (Favicon, Apple-Touch-Icon, Social, Store) |
| `favicon.ico` | 16, 32 und 48 px |

Regeln: immer auf dunklem Grund, nicht umfärben, nicht neu anordnen. Unter 32 px trägt das Motiv nur noch als farbiger Wirbel.
